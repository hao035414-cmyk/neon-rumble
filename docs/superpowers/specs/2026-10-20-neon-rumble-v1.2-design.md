# NEON RUMBLE v1.2 设计与平衡修订（2026-10-20）

状态：待批准（批准后实施）
范围：玩法/帧数据/连招/攻防/CPU/测试；不改美术风格、不联网、不加角色。

## 1. 诊断：为什么现在「会被连到死」

用仓库现有代码跑脚本探针（`tmp/probe.mjs`，角落实测，P1 只按轻拳）：

| 场景 | 结果 |
| --- | --- |
| P2 完全不操作 | 93 次命中，1000 伤害，1754 帧（29.2 秒）KO |
| P2 一直按后防御 | 93 次命中，1000 伤害，1772 帧 KO |
| P2 硬直结束就抢轻拳 | 93 次命中，1000 伤害，1754 帧 KO |

根因（全部来自 `src/config.js` + `src/fighter.js`）：

1. 轻拳 `lp`：起手 4 / 判定 3 / 收招 7（共 14 帧），命中在第 5 帧，攻击方第 14 帧自由；对手 `hitstun` 13 帧 → **命中后 +4 帧**，而轻拳起手只要 4 帧 → 可以无限自我连段。
2. 主力技在「命中」时反而是负帧：重拳 18 − (30 − 10) = **−2**，下段 14 − (26 − 9) = **−3**。打中人反而先被对面动，所以最优解只有轻拳。
3. `hitstun` 不随连段衰减，击退不随连段衰减，伤害只降到 40% 保底 → 连段只能靠「距离/墙」结束，墙角即无限。
4. 防守手段只有站/蹲防：没有投技、没有中段、没有无敌反击、没有后撤步 → 被压就无解。
5. AI 在同一帧读到 `opponent.attacking` 就按概率防御/防空，没有反应延迟，且没有任何胜率测量手段（PRD R5 要求 40%–60% 但无法验证）。

## 2. 目标 / 非目标

目标：
- 任何角色、任何位置都不存在无限连（CI 自动断言）。
- 每个招式都有明确用途，命中收益与风险成正比。
- 连招是「资源+取消」的选择，而不是「按同一个键」。
- 攻防有循环：投 → 拆投 / 防 → 投 / 压 → 升龙或后撤。
- 用可复现的自动对局测量平衡（镜像胜率、难度梯度、最长连段）。

非目标：联网、新角色、新场景、移动端触屏、回放。

## 4. 连招系统

- **取消**：普通技在命中/防御后的判定帧与收招帧可取消为波/EX 波/超杀（空挥不可取消）。这是主要连段来源。
- **浮空**：`launch` 命中把对手打浮空，允许追加一次空中攻击（伤害 40%），落地后浮空状态清零。
- **硬直衰减**：连段第 n 次命中，hitstun × max(0.55, 1 − 0.12n)；**这是「不可能连到死」的结构性保证**。
- **击退衰减**：push × max(0.35, 0.85^n)，避免墙角无限压。
- **伤害衰减**：100% / 90% / 81% / …，保底 30%（原 40%，配合硬直衰减更平滑）。
- **连段计时**：40 帧无新命中清零（原 54）。
- **连段上限**：设计目标单套 ≤ 6 段、≤ 45% 满血；由 CI 断言。

## 5. 攻防公平

- **投技**：近距离不可防，120 伤害；成立后 8 帧内双方同按「轻+重」则拆投，双方弹开。
- **中段**：前 + 踢（不是新键），必须站防。
- **升龙**：→↓↘ + 重拳，1–8 帧无敌，防御 −22（被防重罚）。
- **后撤步**：双击后方向，16 帧 / 90px，其中 5 帧无敌；**前冲**：双击前方向，14 帧 / 120px。两者都用于对抗波动。
- **投射物相杀**：双方投射物相撞同时消失；超杀撞普通波时超杀存活。
- **平局上限**：最多 5 回合；第 5 回合仍无人 2 胜则判平局（原「不设上限」会产生无限对局）。

## 6. 输入

- 6 帧输入缓冲（按键在 6 帧内有效），解决「按了没出」。
- 指令识别：QCF（26 帧内）→ 波；DP（前→下→前下）→ 升龙，优先级高于 QCF；双 QCF → 超杀。
- 双击方向 → 冲/后撤（12 帧内两次）。
- 同一帧「轻+重」→ 投技。
- 保留：按下沿触发、失焦暂停、方向键不滚动页面。

## 7. 角色与 CPU

角色差异（小步长，避免换皮）：
- KAI：走速 3.4、跳 15.6、波伤害 72 → 立回/牵制。
- RIN：走速 3.1、跳 14.8、重拳 64、踢 84 → 爆发/惩罚。
- 目标：同水平 AI 镜像与跨角色胜率落在 45%–55%。

CPU：
- 观察延迟（难度 0.8/1.0/1.2 → 12/8/5 帧），不得读取未来状态。
- 新增：确反（对手收招 >12 帧且距离 <100 时进攻）、升龙对空（30%）、拆投（40%）。
- `tools/balance.mjs`：默认 200 局 AI 对局，输出胜率/平均回合/最长连段；PRD R5 的 40%–60% 由此测量。

## 8. 测试方案（交付时必须全绿）

1. 原有 7 组测试全过。
2. 新增帧差断言：逐招验证表 3 的 hitAdv/blockAdv。
3. 新增反无限连断言：脚本化轻拳压制 60 秒，最长连段 ≤ 6，总伤害 < 45% 满血。
4. 新增：硬直/击退/伤害衰减、浮空追加、取消（命中可取消/空挥不可）、投技与拆投、升龙无敌帧、投射物相杀、平局上限。
5. 平衡：`node tools/balance.mjs` 200 局，镜像胜率 45%–55%，难度 0.8 < 1.0 < 1.2。
6. 性能：Node 下 10,000 帧 update < 500ms。
7. 浏览器冒烟：headless Edge 截图标题页与对局（虚拟时间 3 秒），确认无 JS 报错、canvas 有内容。

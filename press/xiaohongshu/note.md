## 正文（直接复制）

最近想验证一件事：一个像样的格斗游戏，到底需要多少代码？

答案是 2000 行左右，而且零依赖。

🎮 它现在能做什么
· 三局两胜、99 秒读秒，KO / 时间到判定
· 轻拳、重拳、踢、下段、跳入、波动、100 气超杀
· 起手帧 / 判定帧 / 收招帧，命中硬直、防御硬直、击倒、起身无敌
· 下段必须蹲防，跳跃攻击是 overhead，波动有削血
· 连段伤害递减，不会被一套带走
· CPU 会接近、立回、防空、发波，也会防御

🛠 技术上
纯 Canvas 2D + 原生 ES modules，没有引擎、没有构建、没有图片素材——角色和场景都是代码画的。
战斗模拟层完全不碰 DOM，所以能直接在 Node 里跑测试：7 组断言全绿，CI 每次 push 都跑。

⌨️ 怎么玩
浏览器打开就能打，键盘操作：
WASD 移动，J 轻拳 / K 重拳 / L 踢
↓↘→ + 攻击 = 波动；↓↘→↓↘→ + 重拳 = 超杀
（手机只能看，需要键盘）

📦 开源
MIT。试玩地址和代码放在评论区置顶。

最大的收获：格斗游戏的“手感”不是玄学，是帧表和硬直一帧一帧堆出来的。
